# HevyLift

A simple React + Vite app for tracking a 3-day gym workout split with linear periodization.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Features

- Week 1-6 progression
- Day A, B, and C workout rotation
- Target rep phase logic: 10 / 6 / 4 reps
- Simple dark theme UI

## Project structure

- `src/App.jsx` – main workout tracker UI
- `src/index.css` – styling
- `vite.config.js` – Vite configuration
